DOCUMENTAÇÃO INICIAL DO BACK-END MEDCONNECT

# STACK
## Linguagem
- JavaScript com Node.js

### Desenvolvimento (Core)
- express.js: Framework minimalista para criação de servidores HTTP e APIs (gerenciamento de rotas e middlewares).
- prisma: ORM (Object-Relational Mapping) para comunicação estruturada com o banco de dados, versionamento de tabelas e execução de queries.
- pg (PostgreSQL): Driver nativo para comunicação de baixo nível com o banco PostgreSQL (utilizado pelo Prisma nos bastidores).
- zod: Biblioteca de validação de schemas. Utilizada para garantir que o formato e a sintaxe dos dados recebidos na requisição estejam corretos antes de passarem para as regras de negócio.
- multer: Middleware para processamento de requisições `multipart/form-data`, essencial para o recebimento e armazenamento de arquivos.
- dayjs: Biblioteca leve para manipulação simplificada e segura de datas, cálculos de prazos e fusos horários.

### Documentação
- redoc: Bibliotecas conjuntas para ler anotações no código e gerar a interface gráfica interativa da documentação da API no padrão OpenAPI.

### Segurança
- jsonwebtoken:Biblioteca para geração e validação de tokens de autenticação (JWT) sem necessidade de armazenar sessões no servidor.
- bcryptjs: Biblioteca para aplicação de funções de hash em senhas antes do salvamento no banco de dados.
- cors: Middleware para configuração do Cross-Origin Resource Sharing, permitindo que aplicações front-end acessem a API.
- helmet: Coleção de middlewares de segurança que ajustam os cabeçalhos HTTP para blindar a API contra vulnerabilidades comuns da web.
- express-rate-limit: Middleware para controle de tráfego, limitando o número de requisições que um mesmo IP pode fazer em um intervalo de tempo.

### Recursos e Qualidade (DevDependencies)
- Recursos Nativos do Node.js: Uso das flags `--watch` (substitui o *nodemon* reiniciando o servidor ao salvar arquivos) e `--env-file` (substitui o *dotenv* carregando variáveis de ambiente automaticamente).
- pino e pino-pretty: Biblioteca de logs estruturados em JSON de altíssima performance (`pino`) acompanhada de um formatador para tornar a leitura amigável no 
- eslint e prettier: Ferramentas para analisar erros estáticos e forçar um padrão visual único de formatação no código de toda a equipe.
